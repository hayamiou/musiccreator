Un ticket est considéré comme "FAIT" quand :
✅ Le code est écrit et fait ce qui est demandé
✅ Le code fonctionne sans erreur dans la console
✅ La fonctionnalité a été testée manuellement par le développeur
✅ Le code est poussé sur le repository Git
✅ La fonctionnalité est validée par le Product Owner
